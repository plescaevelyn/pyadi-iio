# Automation workshop setup

On a linux environment:

## Installation

git clone https://github.com/constmonica/pyadi-iio to clone the repository

```bash
cd pyadi-iio
```

Checkout the correct branch
```bash
git checkout swiot
```
Install pyadi
```bash
sudo pip install .
```

## Usage

```bash
cd pyadi-iio/examples/workshop
python3 exercise_2.py
```
